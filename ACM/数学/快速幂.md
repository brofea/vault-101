# 快速幂

## 朴素快速幂

快速求 $m^k\mod p$，时间复杂度是 $O(\log k)$

### 思路（朴素快速幂）

可以将 $m^k$ 拆成 $m^{k_0}m^{k_1}m^{k_2}...m^{k_n}$ 多个乘积，然后分别取余

其中 $k=k_0+k_1+k_2+...+k_n$，其实 $k_i$ 就是二进制 $k$ 的每一位数再乘 $2^i$，只会等于 $2^i$ 或 1

每次用 `k&1` 取到 $k$ 的最低位，如果等于 1 说明当前的 $m^{k_i}$ 是 $m^k$ 的因子，更新 res

`t` 用于存 $m^{k_i}$ 取模后的值

### 模板（朴素快速幂）

```C++
int qpow(int m, int k, int p) {
  int res = 1 % p, t = m;
  while (k) {
    if (k & 1) res = res * t % p;
    t = t * t % p;
    k >>= 1;
  }
  return res;
}
```

### 应用：求乘法逆元

总而言之：

$$(x\div y) \mod p =(x\mod p)\times y^{p-2}$$

模意义下乘法运算的逆元的定义：

> 如果一个线性同余方程 $bx\equiv 1\space(\mod m)$，则 $x$ 称为 $b$ 模 $m$ 的逆元，记作 $b^{-1}$

乘法逆元的优势就是在模意义下将除法转换为乘法，例如要求 $(x/y)\mod m$，就可以转化为求 $(x\mod m)\times y^{-1}(\mod m)$

扩展定义：

$$bx\equiv 1\iff a\equiv abx \iff a/b\equiv ax \space (\mod m)$$

> 若 $b$ 和 $m$ 互质且 $a/b \in \mathbb{Z}$，那么对 $a/b\equiv ax\space(\mod m)$ 求解 $x$ 就是求解逆元，$x$ 称为 $b$ 的模 $m$ 乘法逆元

- 形如 $ax\equiv b(\mod n)$ 求解全体 $x$ 的方程称为线形同余方程

- $a/b \in \mathbb{Z}$ 和 $b \mid a$ 都代表：“ $b$ 能整除 $a$ ”

- $x$ 可以记作 $b^{-1}$ （不是真的是 $1/b$ ），这样记就使 $bb^{-1}\equiv 1$ 更为形象

- $b$ 存在乘法逆元的充要条件是 $b$ 与 $m$ 互质

当 $m$ 为质数的时候（记为 $p$ ），根据费马小定理：

$$bx\equiv 1\iff bx\equiv b^{p-1} \iff x\equiv b^{p-2} (\mod p)$$

$b^{m-2}$ 即为 $b\mod p$ 的乘法逆元

**在快速幂求逆元法中，费马小定理要求** $m$ **一定是质数，快速幂法才能求解。**即对 $bx\equiv 1\space(\mod p)$ 求解 $x$，此时 $x=b^{p-2}$，由于 $p$ 是质数，所以 $p-2$ 恒大于等于 $0$，这样一来就将问题转化为了简单的快速幂问题，代码同模板没有区别

具体实现时候要注意 $b$ 和 $p$ 不互质的情况和 $p$ 为 $2$ 的情况
