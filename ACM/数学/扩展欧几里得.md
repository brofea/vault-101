# 数学——扩展欧几里得算法及其应用

## 裴蜀定理

> [OI Wiki - 裴蜀定理](https://oi-wiki.org/math/number-theory/bezouts/)
> 设 $a\space b$ 是不全为零的整数，对任意整数 $x\space y$，满足 $\gcd(a,b)\mid ax+by$，且存在整数 $x\space y$, 使得 $ax+by=\gcd(a,b)$

## 扩展欧几里得算法

欧几里得算法（又称辗转相除法）的目标是给定 $a\space b$ 求解 $\gcd(a,b)$，而扩展欧几里得算法就是要求解一对整数 $x\space y$ 使得 $ax+by=\gcd(a,b)$，这里的 $x \space y$ 其中一个很有可能是负数，且 $x\space y$ 不唯一

### 函数什么时候返回？

记最大公约数为 $d$，在欧几里得算法中 $\gcd(a,0)=a$，所以特殊地 $exgcd(a,0,x,y)=a$，此时应计算 $ax+0y=a$，显然 $x=1$，返回值为 $a$

### $y$ 怎么计算？

因为有：$a \mod b = a-\lfloor a/b \rfloor \cdot b$

所以：$ax+by=d\iff (a-\lfloor a/b \rfloor \cdot b)x+by=d\iff ax+b(y-\lfloor a/b \rfloor x)=d$

所以有：$y=y-\lfloor a/b \rfloor x$，体现在程序中，`y-=(a/b)*x`

### 怎么求出其他的解

$ax+by=d\iff a(x-b/d)+b(y+a/d)=d$

若其中一解为 $x_0 \space y_0$，则其他解为：

$\left\{ \begin{aligned} x=x_0-\frac b d*k,\space k \in \mathbb{Z}\\ y=y_0+\frac a d*k,\space k \in \mathbb{Z}\end{aligned} \right.$

```C++
int exgcd(int a, int b, int &x, int &y)
{
    if (!b)
    {
        x = 1; y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x);
    y -= (a/b) * x;
    return d;
}
```

### 应用：线性同余方程

给定 $a\space b\space m$，求解 $ax\equiv b(\mod m)$

$ax\equiv b(\mod m) \iff ax=my+b\iff ax-my=b\iff ax+my'=b$

不难看出将原方程转化为扩展欧几里得算法求解的 $ax+by=\gcd(a,b)$，观察 $ax+my'=b$，只有 $\gcd(a,m)\mid b$，也就是 $b$ 是 $\gcd(a,m)$ 的倍数这个方程才有解

假设 $b$ 是 $\gcd(a,m)$ 的 $k$ 倍，即 $b=kd$，则只需要求解 $ax_0+my'_0=d$，就能求出原方程 $x=kx_0,\space y=-ky'_0$

例题：

> [落谷 - P1082 [NOIP2012 提高组] 同余方程](https://www.luogu.com.cn/problem/P1082)  

求解 $ax\equiv 1(\mod b)\iff ax=by+1 \iff ax+by‘=1$

```C++
\#include <bits/stdc++.h>
using namespace std;
void exgcd(int a,int b,int &x,int &y){
  if(!b) {x=1,y=0;return;}
  exgcd(b,a%b,y,x);
  y-=(a/b)*x;
}
int main(){
  int a,b,x,y;
  cin>>a>>b;
  exgcd(a,b,x,y);
  cout<<(x<0?x+b:x)<<endl;
}
```

## 中国剩余定理 CRT

给定一组两两互质的数：$m_1,m_2,m_3\dots m_k$，有一组数 $a_1,a_2,a_3\dots a_k$  
满足 $x\equiv a_i(\mod m_i),i \in [1,k]$

设 $M=\prod_{i=1}^k m_i$，$M_i=M/m_i$，由于 $m_i$ 两两互质，所以 $M_i$ 与 $m_i$ 互质，记 $M_i^{-1}$ 为 $M_i$ 模 $m_i$ 的逆，$x$ 就有公式解：

$$x=\sum_{i=1}^{k}(a_i\cdot M_i\cdot M_i^{-1})$$

在 $ax\equiv 1(\mod m)$ 中 $x$ 为 $a\mod m$ 的逆元，所以求 $M_i^{-1}$ 就可以用扩展欧几里得算法对$M_ix\equiv 1(\mod m_i)$ 求解 $x$

$M_i\cdot M_i^{-1} \mod m_i=1$，$(a_i\cdot M_i\cdot M_i^{-1})$ 的其他项中都有 $m_i$ 作为因数，所以模 $m_i$ 都为 $0$，所以 $x\equiv a_i(\mod m_i)$ 恒成立

> [落谷 - P1495 【模板】中国剩余定理（CRT）/ 曹冲养猪](https://www.luogu.com.cn/problem/P1495)  

- AC 代码，包括了 exgcd、逆元、CRT 的模板

```C++
\#include <bits/stdc++.h>
using namespace std;
using ll = long long;
// 扩展欧几里得算法，求解 ax + by = gcd(a, b)
ll exgcd(ll a, ll b, ll &x, ll &y) {
    if (!b) {
    x = 1;
    y = 0;
    return a;
    }
    ll d = exgcd(b, a % b, y, x);
    y -= (a / b) * x;
    return d;
}
// 求 a 模 p 下的逆元
ll mmi(ll a, ll p) {
    ll x, y;
    exgcd(a, p, x, y);
    return (x % p + p) % p;
}
// 中国剩余定理, 求解 x ≡ a[i] (mod m[i])
ll CRT(ll a[], ll m[], int n) {
    ll PM = 1, Mi, MiR, tmp, res = 0;
    for (int i = 1; i <= n; ++i) 
    PM *= m[i];
    for (int i = 1; i <= n; ++i) {
    Mi = PM / m[i];
    MiR = mmi(Mi, m[i]);
    tmp = (__int128)a[i] * Mi * MiR % PM;
    res = (res + tmp) % PM;
    }
    return res;
}
int main() {
    const int N = 15;
    ll n, a[N], m[N];
    cin >> n;
    for (int i = 1; i <= n; ++i)
    cin >> m[i] >> a[i];
    cout << CRT(a, m, n) << endl;
    return 0;
}
```
