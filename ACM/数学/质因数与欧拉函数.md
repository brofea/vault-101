# 数学——质因数与欧拉函数

## 质数

> 质数，又称素数，指在大于1的自然数中，除了1和该数自身外，无法被其他自然数整除的数（也可定义为只有1与该数本身两个正因数的数）

### 判断质数——试除法

> $\text{若 } d \mid n, \text{ 则 } \frac{n}{d} \mid n.$

由于 x 的因数 / 约数是成对出现的，所以循环时只需要循环到 $\sqrt x$

- 不推荐写成 `i<=sqrt(x)` 计算平方根的函数太慢

- 不推荐写成 `i*i<=x` 因为 `i` 的平方可能会溢出，（如果 i 不超过46000则可以）

- 可以写成 `i<=x/i` 或先计算 `e=sqrt(n)+1;`

- 由于 2 和 3 的倍数可以筛掉 $2/3$ 的数，所以可以对其进一步优化，只判断 $6k\pm 1$ 的数

```C++
bool isPrime(int n){
  if(n<=1 || n%2==0 || n%3==0) return false;
  if(n<=3) return true;
  int e=sqrt(n);
  for(int i=5;i<=e;i+=6)
    if(n%i==0 || n%(i+2)==0)
        return false;
  return true;
}
```

以上模板时间复杂度为 $O(\sqrt n/3)$

### 判断质数——筛法

朴素筛就是筛掉每一个数的倍数，用调和级数可算，时间复杂度为：$O(n\ln n)<O(n\log n)$

埃拉托斯特尼筛法就是只筛掉每个质数的倍数，由质数定理：$1～n$ 之中有 $n/\ln n$ 个质数，时间复杂度为 $O(n\log \log n)$ 和 $O(n)$ 为同一级别

```C++
// 找到0-n的所有质数
vector<bool> isPrime(n+1,1);
isPrime[1]=0,isPrime[0]=0;
int e=sqrt(n);
for(int i=2;i<=e;i++)
    if(isPrime[i]==1)
        for(int j=i+i;j<=n;j+=i)
            isPrime[j]=0;
```

线形筛又称为欧拉筛，基本思路就是：每个数只由它的最小质因子筛去标记为合数，从而避免重复标记并确保线性复杂度。每次循环到 i 的时候，都把先前找到的所有质数和 i 相乘，标记它们为合数

但是要注意 `if(i%k==0) break;` 这一句，因为此时质数 k 是 i 的最小质因子，k 也一定是 k*i 这个数被最小质因子 ，因为要保证每个数只由它的最小质因子筛去，所以筛完之后就`break;`

线形筛 / 欧拉筛的时间复杂度为 $O(n)$

```C++
const int N = 100;
vector<int> isPrime(N + 1, 1);
vector<int> primes;
isPrime[0] = isPrime[1] = 0;
for(int i = 2; i <= N; ++i){
  if(isPrime[i])
    primes.push_back(i);
  for(int k : primes){
    if(i * k > N) break;
    isPrime[i * k] = 0;
    if(i % k == 0) break;
  }
}
```

### 分解质因数——试除法

基本思路和求质数试除法一样

以下模板分解质因数时每行会按照“质因数+幂次”的格式输出，输出了 11 2 说明该数为 11*11=121

```C++
void divide(int x)
{
    for (int i = 2; i <= x / i; i ++ )
        if (x % i == 0)
        {
            int s = 0;
            while (x % i == 0) x /= i, s ++ ;
            cout << i << ' ' << s << endl;
        }
    if (x > 1) cout << x << ' ' << 1 << endl;
    cout << endl;
}
```

## 因数

### 求所有因数——试除法

基本思路就是和求质数的试除法一样，循环到 $\sqrt x$ 即可，一次放入两个约数，最后再排序。要注意的是如果约束恰好是 $\sqrt x$ 就不能放入两个数

```C++
vector<int> get_divisors(int x)
{
    vector<int> res;
    for (int i = 1; i <= x / i; i ++ )
        if (x % i == 0)
        {
            res.push_back(i);
            if (i != x / i) res.push_back(x / i);
        }
    sort(res.begin(), res.end());
    return res;
}
```

一个数 n 的约数个数也是大约有 $\log n$ 个，所以排序的时间复杂度为 $O(\log n \log \log n)$，相较于前面的 $O(\sqrt n)$ 可以忽略不计，所以时间复杂度就为 $O(\sqrt n)$

### 约数个数和约数之和问题

如果一个数 n 质因数分解后得到：

$$n = p_1^{a_1}\times p_2^{a_2}\times p_3^{a_3}\times ......\times p_k^{a_k}$$

**那么约数个数为：**

$$(a_1+1)(a_2+1)(a_3+1)......(a_k+1)$$

因为对于 $n$ 的任意约数 $d$，都有 $d = p_1^{b_1}\times p_2^{b_2}\times p_3^{b_3}\times ......\times p_k^{b_k}$，所以约数个数就是所有 $b$ 能取的个数集，对于任意 $b_i$ 都可以取 $0～a_i$ 一共 $a_i+1$ 个数，计算 $b$ 的所有排列就可以得到约数个数

可以简单记为：

$$\prod_{j=1}^k (a_j+1)$$

- int 范围内的数的约数最多大约是 1500 个

**约数之和为：**

$$\sum_{j=0}^{a_1} p_1^j \times \sum_{j=0}^{a_2} p_2^j \times \sum_{j=0}^{a_3} p_3^j \times ...... \times \sum_{j=0}^{a_k} p_k^j$$

因为相当于每一项 $\sum$ 中取出一项相乘得到一个约数，求和就是各个项相加再相乘，用乘法分配律展开就是每个约数之和

或者记为：

$$\prod_{u=1}^k \sum_{j=0}^{a_u} p_u^j$$

### 欧几里得算法

基本原理：

$\gcd(a,b)=\gcd(b,a\mod b)$ 特殊地 $\gcd(a,0)=a$

```C++
int gcd(int a, int b)
{
    return b ? gcd(b, a % b) : a;
}
```

```C++
int lcm(int a,int b) {
    return (a / gcd(a, b)) * b;
}
```

要注意最小公倍数要先除再乘，避免超过数据范围

## 欧拉函数

> [OI Wiki - 欧拉函数](https://oi-wiki.org/math/number-theory/euler-totient/)
> 在数论中，对正整数n，欧拉函数 $\varphi (n)$ 是小于等于 n 的正整数中与 n 互质的数的数目

### **一般因式分解性质**

如果一个数 n 质因数分解后得到：

$$n = p_1^{a_1}\times p_2^{a_2}\times p_3^{a_3}\times ...\times p_k^{a_k}$$

那么：

$$\varphi (n)=n(1-\frac1 p_1)(1-\frac1 p_2)...(1-\frac1 p_k)$$

可以看出欧拉函数和质因数的幂次无关，只与质因数的种类有关。

### 证明：容斥原理

用 n 先减去所有 $p_i$ 的所有倍数：

$$\varphi (n)= n-\frac n p_1-\frac n p_1-...-\frac n p_k$$

由于 $p_ip_j$ 会被 $p_i$ 和 $p_j$ 减两次，所以要加回来：

$$\varphi (n)= n-\frac n p_1-\frac n p_2-...-\frac n p_k +\frac n {p_1p_2}+\frac n {p_1p_3}+...$$

由于 $p_ip_jp_l$ 会被减三次，又加三次，所以要再减回来，同理 $p_ip_jp_lp_m$ 要加回来，$p_ip_jp_lp_mp_n$要被减去……

$$\varphi (n)= n-\frac n p_1-\frac n p_2-...+\frac n {p_1p_2}+\frac n {p_1p_3}+...-\frac n {p_1p_2p_3}-...+\frac n {p_1p_2p_3p_4}+.......$$

上式整理后即可得到原式

```C++
int phi(int x)
{
    int res = x;
    for (int i = 2; i <= x / i; i ++ )
        if (x % i == 0)
        {
            res = res / i * (i - 1);
            while (x % i == 0) x /= i;
        }
    if (x > 1) res = res / x * (x - 1);

    return res;
}
```

### 其他性质

若有质数 $p$，则

$$\varphi (pn)=p\varphi (n)(1-\frac1 p)=(p-1)\varphi (n)$$

欧拉函数的乘法性质 $φ(a⋅b)=φ(a)⋅φ(b)$

欧拉函数的质数性质 $φ(p)=p−1$

欧拉函数质数幂性质 $φ(pk)=p^k−p^{k−1}=p^k(1−\frac 1 p​)$

由上述性质就可以写出利用筛法的欧拉函数：

```C++
int primes[N], cnt;     // primes[]存储所有素数
int euler[N];           // 存储每个数的欧拉函数
bool st[N];         // st[x]存储x是否被筛掉


void get_eulers(int n)
{
    euler[1] = 1;
    for (int i = 2; i <= n; i ++ )
    {
        if (!st[i])
        {
            primes[cnt ++ ] = i;
            euler[i] = i - 1;
        }
        for (int j = 0; primes[j] <= n / i; j ++ )
        {
            int t = primes[j] * i;
            st[t] = true;
            if (i % primes[j] == 0)
            {
                euler[t] = euler[i] * primes[j];
                break;
            }
            euler[t] = euler[i] * (primes[j] - 1);
        }
    }
}
```

### 欧拉定理

> 若 $\gcd (a,n)=1$ 则 $a^{\varphi(n)}\equiv 1 (\mod n)$

例如 5 和 6 互质，$\varphi(6)=2$，$5^2\mod 6=1$

### 费马小定理

> 若 $p$ 为质数且 $\gcd(a,p)=1$ 则 $a^{p-1}\equiv 1 (\mod p)$
> 对于任意整数 $a$，$a^p \equiv 1(\mod p)$
