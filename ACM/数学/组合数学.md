# 组合数学

$$A_a^b=a(a-1)(a-2)\cdots(a-b+1)=\frac{a!}{(a-b)!}$$

$$C_a^b=\frac{a(a-1)(a-2)\cdots(a-b+1)}{1\times2\times3\cdots\times b}=\frac{a!}{b!(a-b)!}=\frac{A_a^b}{b!}$$

模意义下求组合数问题：每次查询给定 $a,b$，求 $C_a^b \mod p$，即在 $a$ 个物品中选择 $b$ 个总共的选法数量模 $p$ 的值，共有 $n$ 组查询

求组合一共有以下算法，附带他们大致适用的数据范围和时间复杂度

1. 递推法：$n\le 10^5,1 \le b \le a \le 2000,O(n^2)$
2. 预处理：$n\le 10^5,1 \le b \le a \le 10^5,O(n\log n)$
3. Lucas：$n\le 20,1 \le b \le a \le 10^18,1 \le p \le 10^5,O(p\log n \log p)$
4. 分解质因数：$1 \le b \le a \le 5000$，*不模 $p$

## 递推法

**适用数据范围小，查询次数多的模意义求组合数**，原理如下：

$$C_a^b=C_{a-1}^b+C_{a-1}^{b-1}$$

和 01 背包问题相似，若要在 $a$ 个物品中选择 $b$ 个，对于其中一个物品 $x$，可以选择它，也可以不选。

如果选择 $x$，那就还要在剩下的 $a-1$ 个物品中选择 $b-1$ 个，如果不选 $x$，那就仍然要在剩下的 $a-1$ 个物品中选 $b$ 个，也就是 $C_{a-1}^{b-1}$ 和 $C_{a-1}^b$

求出的数组是一个直角三角形，在 i 为 0 时 j 循环到 0 就停止，所以不会发生越界访问

```C++
// c[a][b] 表示从a个苹果中选b个的方案数
int c[N][N]={0};
for (int i = 0; i < N; i ++ )
    for (int j = 0; j <= i; j ++ )
        if (!j) c[i][j] = 1;
        else c[i][j] = (c[i - 1][j] + c[i - 1][j - 1]) % mod;
```

## 预处理

**适用数据范围中等，查询次数多的模意义求组合数**，原理如下，已知：

$$C_a^b=\frac{a!}{b!(a-b)!}$$

可以先求出数据范围内所有的阶乘，但是 $x!/y!\not=(x!\mod M)/(y!\mod M)$，所以不能直接用取模后的预处理阶乘计算 $C_b^a$，要用逆元

逆元能将取模意义下的除法运算转化为乘法运算，除以 $x!$ 相当于乘以 $x!\mod M$ 的逆元，可以先预处理出数据范围内所有阶乘和阶乘的逆元 $f_i$ 和 $f_i^{-1}$，则 $C_a^b=f_a\times f_b^{-1} \times f_{a-b}^{-1}$

如果去模的数是质数，可以用费马小定理和快速幂求逆元，如果不是就用扩展欧几里得算法，相当于解 $ax\equiv 1(\mod m)$ 的方程

费马小定理求阶乘逆元：

记 $a!$ 模 $m$ 的逆元为 $(a!)^{-1}$ 根据乘法逆元性质展开：

$$(a!)^{-1}=((a-1)!\times a)^{-1}=((a-1)!)^{-1}\times a^{-1} \space ①$$

> 费马小定理推论：$b^{-1}=b^{p-2}\mod p$

根据费马小定理推论和式 $①$ 可以得到递推公式：

$$f_i^{-1}=f_{i-1}^{-1}\times i^{-1}=f_{i-1}^{-1}\times i^{p-2}\mod p$$

```C++
int qmi(int a, int k, int p)    // 快速幂模板
{
    int res = 1;
    while (k)
    {
        if (k & 1) res = (LL)res * a % p;
        a = (LL)a * a % p;
        k >>= 1;
    }
    return res;
}

// 预处理阶乘的余数和阶乘逆元的余数
fact[0] = infact[0] = 1;
for (int i = 1; i < N; i ++ )
{
    fact[i] = (LL)fact[i - 1] * i % mod;
    infact[i] = (LL)infact[i - 1] * qmi(i, mod - 2, mod) % mod;
}
```

- 每次求完阶乘逆元和求阶乘一样要取模

- 快速幂模板是求 $a^k\mod p$ 的值

- 如果 fact 和 infact 数组是 int 类型要强制类型转换

**适用数据范围大，查询次数少的模意义求组合数**，卢卡斯定理的内容如下：

若 $p$ 是质数，最对于任意正整数 $a,b$

$$C_a^b\equiv C_{(a\mod p)}^{(b\mod p)}\cdot C_{\lfloor a/p \rfloor }^{\lfloor b/p \rfloor}(\mod p)$$

在离散数学中，使用二项式系数符号表示 $C_a^b$，即 $\binom{a}{b}$ ，也能写成：

$$\binom{a}{b}\mod p=\binom{\lfloor a/p \rfloor }{\lfloor b/p \rfloor}\cdot\binom{a\mod p}{b\mod p}  
\mod p$$

使用 Lucas 定理的时间复杂度是：$O(\log_p n\times p \times \log p)\approx O(p\log n\log p)$

***证明：**

将 $a,b$ 表示为 $p$ 进制 $①$：

$$a=a_kp^k+a_{k-1}p^{k-1}+\dots+a_0p^0 \\ b=b_kp^k+b_{k-1}p^{k-1}+\dots+b_0p^0$$

根据二项式定理展开 $(1+x)^p$

$$(1+x)^p=C_p^0x^0+C_p^1x^1+\dots+C_p^px^p=\sum_{i=0}^{p}C_p^ix^i$$

展开的二项式的第一项与最后一项分别为 $1$ 和 $x^p$，在 $i$ 从 $1$ 到 $p-1$ 项中，$C_p^i$ 都带有 $p$，所以对 $(1+x)^p$ 求模时就可以约掉：

$$(1+x)^p\equiv 1+x^p (\mod p) \space ②$$

结合上$①②$式：

$$(1+x)^a=\prod_{i=0}^{k}\left [(1+x)^{p^i}\right] ^{a_i}=\prod_{i=0}^{k}\left (1+x^{p^i}\right) ^{a_i}$$

将上述每一项 $(1+x^{p^i}) ^{a_i}$ 换成组合数：

$$(1+x)^a=\prod_{i=0}^{k}\left[ \sum_{j=0}^{a_i}C_{a_i}^{j}x^{jp^i} \right]$$

观察上述式子左右两侧 $x^n$ 的系数，左侧系数即为 $C_a^b$，观察右侧，在模 $p$ 意义下，由于 $b$ 也表示为了 $p$ 进制：$b=b_kp^k+b_{k-1}p^{k-1}+\dots+b_0p^0$，只有在每一项 $\sum_{j=0}^{a_i}C_{a_i}^{j}x^{jp^i}$ 中，$j$ 取 $b_i$ 才不会被约掉，所以右侧的 $x^n$ 系数为：$C_{a_0}^{b_0}\cdot C_{a_1}^{b_1}\cdots C_{a_k}^{b_k}$，所以就有：

$$C_a^b\equiv C_{a_0}^{b_0}\cdot C_{a_0}^{b_0}\cdots C_{a_k}^{b_k}$$

证毕，若有一项 $b_i>a_i$，则 $C_{a_i}^{b_i}=0$，则 $C_a^b=0$

**代码实现**

> 若p是质数，则对于任意整数 1 <= m <= n，有：`C(n, m) = C(n % p, m % p) * C(n / p, m / p) (mod p)`

`**lucas()**` **函数：**

- 如果 $a,b$ 同时小于 $p$，返回 $C_a^b$

- 否则返回 $C_{(a\mod p)}^{(b\mod p)}\cdot C_{\lfloor a/p \rfloor }^{\lfloor b/p \rfloor}(\mod p)$，由于 $C_{\lfloor a/p \rfloor }^{\lfloor b/p \rfloor}$ 仍然可能超过 $p$ 的范围，所以递归使用`lucas()`函数

`C()` 函数：

- 如果 $a<b$ 返回 $0$

- 计算 $C_a^b$ 原始公式的分子和分母，运算过程模 $p$

- 返回分子乘分母模 $p$ 的逆元，运算过程模 $p$

```C++
int qmi(int a, int k, int p)  // 快速幂模板
{
    int res = 1 % p;
    while (k)
    {
        if (k & 1) res = (LL)res * a % p;
        a = (LL)a * a % p;
        k >>= 1;
    }
    return res;
}

int C(int a, int b, int p)  // 通过定理求组合数C(a, b)
{
    if (a < b) return 0;

    LL x = 1, y = 1;  // x是分子，y是分母
    for (int i = a, j = 1; j <= b; i --, j ++ )
    {
        x = (LL)x * i % p;
        y = (LL) y * j % p;
    }

    return x * (LL)qmi(y, p - 2, p) % p;
}

int lucas(LL a, LL b, int p)
{
    if (a < p && b < p) return C(a, b, p);
    return (LL)C(a % p, b % p, p) * lucas(a / p, b / p, p) % p;
}
```

## 分解质因数法求组合数

适用于求组合数真实值，而非在模意义下求组合数，数据范围即使不大也会得到数字很大的结果

$$C_a^b=\frac{a(a-1)(a-2)\cdots(a-b+1)}{1\times2\times3\cdots\times b}=\frac{a!}{b!(a-b)!}$$

直接使用高精度求 $C_a^b$ 需要写高精度乘法和高精度除法，比较困难而且时间复杂度很高。此方法的思路就是将 $C_a^b$ 分解质因数：

$$C_a^b=p_1^{\alpha_1}\cdot p_2^{\alpha_2}\cdots p_k^{\alpha_k}$$

然后将质因数相乘就能得到结果，只需要写高精度乘法即可。上述的 $a_1,a_2\dots a_k$ 在下面模板中使用 `sum[]` 数组存储

**如何分解质因数？**

记 $a!=\prod p_i^{a_i},b!=\prod p_i^{b_i},(a-b)!=\prod p_i^{c_i}$，则：$C_a^b=\prod p_i^{(a_i-b_i-c_i)}$，因此只需要分开求阶乘的质因数数量就可以

**如何对阶乘分解质因数？**

对于每个阶乘项，可以先用筛法找出数据范围内的所有质数，然后直接枚举每个质数，查询阶乘中该质数出现的次数

记 $a!$ 中的某一个质因数 $p_i$ 的个数为 $g(a!,p_i)$，则：

$$g(a!,p_i)=\left\lfloor \frac a {p_i} \right\rfloor+\left\lfloor \frac a {p_i^2} \right\rfloor+\left\lfloor \frac a {p_i^3} \right\rfloor\dots$$

$a!$ 就是 $1\times 2\times 3\times \dots \times a$，在这个公式中：

第一项就是计算从 $1$ 到 $a$ 中有多少个 $p_i$ 的倍数，这些数每个贡献了一个质因数 $p_i$

第二项就是计算从 $1$ 到 $a$ 中有多少个 $p_i^2$ 的倍数，这些数每个贡献了一个质因数 $p_i$

第三项就是计算从 $1$ 到 $a$ 中有多少个 $p_i^3$ 的倍数，这些数每个贡献了一个质因数 $p_i$

以此类推……

这就是模板中 `get()` 函数的原理

```C++
int primes[N], cnt;     // 存储所有质数
int sum[N];     // 存储每个质数的次数
bool st[N];     // 存储每个数是否已被筛掉

void get_primes(int n)      // 线性筛法求素数
{
    for (int i = 2; i <= n; i ++ )
    {
        if (!st[i]) primes[cnt ++ ] = i;
        for (int j = 0; primes[j] <= n / i; j ++ )
        {
            st[primes[j] * i] = true;
            if (i % primes[j] == 0) break;
        }
    }
}

int get(int n, int p)       // 求n！中的次数
{
    int res = 0;
    while (n)
    {
        res += n / p;
        n /= p;
    }
    return res;
}

vector<int> mul(vector<int> a, int b)       // 高精度乘低精度模板
{
    vector<int> c;
    int t = 0;
    for (int i = 0; i < a.size(); i ++ )
    {
        t += a[i] * b;
        c.push_back(t % 10);
        t /= 10;
    }

    while (t)
    {
        c.push_back(t % 10);
        t /= 10;
    }

    return c;
}

get_primes(a);  // 预处理范围内的所有质数

for (int i = 0; i < cnt; i ++ )     // 求每个质因数的次数
{
    int p = primes[i];
    sum[i] = get(a, p) - get(b, p) - get(a - b, p);
}

vector<int> res;
res.push_back(1);

for (int i = 0; i < cnt; i ++ )     // 用高精度乘法将所有质因子相乘
    for (int j = 0; j < sum[i]; j ++ )
        res = mul(res, primes[i]);
```
