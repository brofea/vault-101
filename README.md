- [JAVA](JAVA/) - Java 及相关技术栈笔记
  - [LANG](JAVA/LANG/) - 语言基础
- [JS](JS/) - HTML / CSS / JavaScript 及相关技术栈笔记
  - [LANG](JS/LANG/) - 语言基础
- [PYTHON](PYTHON/) - 存放 Python 及相关技术栈笔记

## 文档规范

- Markdown 遵循 [markdownlint](https://github.com/DavidAnson/markdownlint) 默认规则，不使用非标准语法糖如 Obsidian 的 `[[]]`
- 非竞赛的 C++ 代码遵循 [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html)，竞赛的 C++ 代码稍有变化

## 快速上手

使用 `git clone` 克隆此文件夹，用 [VSCode](https://code.visualstudio.com/) 或 [Typora](https://typora.io/) 等 Markdown 编辑器打开文件夹即可
